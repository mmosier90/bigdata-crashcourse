# Big Data Engineering Labs

Hands-on exploration of modern data engineering concepts using distributed storage, object storage, NoSQL databases, and distributed processing frameworks.

This repository contains a series of graduate-level labs completed as part of my Master's in Applied Data Science. The exercises introduced the core technologies and workflows used in modern data engineering, focusing on ingesting, storing, querying, and processing large datasets across distributed systems.

---

## Technologies

- Apache Spark (PySpark)
- Hadoop HDFS
- Apache Hive
- Apache Drill
- MinIO Object Storage
- MongoDB
- Apache Cassandra
- Spark SQL
- Docker

---

## Topics Covered

### Distributed Storage
- Hadoop Distributed File System (HDFS)
- Object storage with MinIO
- Managing structured and semi-structured data

### Distributed Data Processing
- PySpark DataFrames
- Spark SQL
- Data transformation and ETL workflows
- Reading and writing distributed datasets

### Data Warehousing
- Hive external and internal tables
- Creating Hive databases
- Exporting analytical datasets

### NoSQL Databases
- MongoDB document storage and indexing
- Cassandra wide-column database design
- Partition keys and clustering keys
- Query optimization and execution plans

### Analytics
- Querying large datasets with Apache Drill
- Schema-on-read architecture
- Working with JSON, CSV, and log data
- Flattening nested JSON structures

---

## Skills Demonstrated

- Designing distributed data workflows
- Loading and transforming large datasets with Spark
- Building Hive data warehouses
- Working with object storage
- Querying distributed data using SQL
- Using NoSQL databases for scalable storage
- Creating indexes and optimizing query performance
- Data ingestion and ETL pipelines
- Schema design for relational and NoSQL systems

---

## What I Learned

These labs provided practical exposure to the architecture commonly found in modern data platforms. Rather than focusing on traditional relational databases alone, the projects introduced distributed storage, scalable data processing, and multiple database paradigms.

Although each lab is intentionally small in scope, together they demonstrate how data moves through a modern analytics ecosystem—from ingestion and storage to transformation and querying using distributed technologies.
